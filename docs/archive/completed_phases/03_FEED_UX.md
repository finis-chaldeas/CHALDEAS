# 03. Feed + 진입점 UX

## Feed 탭의 역할

Feed는 **지구본의 해설자**. 지구본이 "어디서 무엇이"를 보여주면, Feed는 "왜 중요한지"를 알려준다.

---

## 진입 경로 (Entry Points)

처음 오는 사람이 시스템에 진입하는 4가지 경로:

### 경로 1: 추천 에피소드 (SHEBA — 관측 시스템)

> SHEBA는 Fate 세계관에서 미래를 관측하는 시스템. 여기서는 "역사를 관측"하는 큐레이션 시스템.

**개념**: 미리 준비된 역사 시나리오/에피소드를 추천. 하나를 선택하면 해당 시대+지역으로 안내.

```
┌─ SHEBA: 추천 관측 ───────────────────────┐
│                                           │
│ 📖 잔 다르크와 백년전쟁                    │
│    1337-1453 · 프랑스/잉글랜드            │
│    "한 소녀가 나라를 구한 이야기"          │
│    서번트: Jeanne d'Arc, Gilles de Rais   │
│                               [관측 시작] │
│                                           │
│ 📖 아서 왕 전설과 브리튼의 몰락            │
│    CE 400-600 · 브리튼                    │
│    "로마 철수 후 브리튼의 암흑기"          │
│    서번트: Artoria, Merlin, Mordred       │
│                               [관측 시작] │
│                                           │
│ 📖 알렉산더 대왕의 동방원정               │
│    334-323 BCE · 마케도니아→인도           │
│    "세계를 정복한 젊은 왕"                 │
│    서번트: Iskandar, Darius III           │
│                               [관측 시작] │
│                                           │
│ 📖 메소포타미아 — 문명의 새벽              │
│    3000-500 BCE · 이라크                  │
│    "최초의 도시, 최초의 문자, 최초의 법"   │
│    서번트: Gilgamesh, Enkidu              │
│                               [관측 시작] │
│                                           │
│               [더 많은 에피소드 →]         │
└───────────────────────────────────────────┘
```

**[관측 시작] 클릭 시**:
1. 지구본이 해당 지역으로 부드럽게 이동
2. 타임라인이 해당 시대로 설정
3. Feed에 해당 에피소드의 주요 사건들이 순서대로 표시
4. 지구본에 이동 경로가 표시 (알렉산더의 원정 경로 등)

### 경로 2: 세계사 연표 (LAPLACE — 해설 시스템)

> LAPLACE는 Fate 세계관에서 설명/해석을 담당. 여기서는 "세계사를 안내"하는 시스템.

**개념**: 시대순으로 주요 사건들을 소개하며 들어가는 연표 방식.

```
┌─ LAPLACE: 세계사 관측 ─────────────────────┐
│                                             │
│ ◆ 고대 (BCE 3000 ~ CE 500)                │
│   ├─ 메소포타미아 문명 (BCE 3000~)          │
│   ├─ 이집트 고왕국 (BCE 2686~)              │
│   ├─ 그리스-페르시아 전쟁 (BCE 499~449)     │
│   ├─ 알렉산더 대왕 (BCE 336~323)            │
│   ├─ 포에니 전쟁 (BCE 264~146)              │
│   └─ 로마 제국 (BCE 27~CE 476)              │
│                                             │
│ ◆ 중세 (CE 500 ~ 1500)                    │
│   ├─ 이슬람 황금기 (CE 750~1258)            │
│   ├─ 십자군 전쟁 (1096~1291)                │
│   ├─ 몽골 제국 (1206~1368)                  │
│   └─ 백년전쟁 (1337~1453)                   │
│                                             │
│ ◆ 근세 (1500 ~ 1800)                      │
│   ├─ 대항해 시대 (1400~1600)                │
│   ├─ 르네상스 (1400~1600)                   │
│   └─ ...                                    │
│                                             │
│ 아무거나 클릭 → 해당 시대로 지구본 이동     │
└─────────────────────────────────────────────┘
```

**기존 EraTab의 확장 버전.** 각 항목에:
- 한 줄 설명
- 관련 서번트 아이콘 (있으면)
- 클릭 → 지구본 이동 + Feed 필터링

### 경로 3: 주요 인물 (PAPERMOON — 인물 검증)

> PAPERMOON은 Fate에서 팩트체킹 시스템. 여기서는 "인물의 진짜 역사"를 보여줌.

**개념**: 유명 역사 인물 카드 갤러리. 서번트 연결이 있으면 표시.

```
┌─ PAPERMOON: 주요 인물 ──────────────────────┐
│                                              │
│ [시대 필터: 전체 ▼] [지역 필터: 전체 ▼]      │
│                                              │
│ 👤 알렉산더 대왕        👤 율리우스 카이사르  │
│    356-323 BCE             100-44 BCE        │
│    마케도니아 왕            로마 독재관        │
│    ★★★★★                  ★★★★★             │
│    🎮 Iskandar             🎮 Caesar         │
│                                              │
│ 👤 잔 다르크              👤 레오나르도 다빈치 │
│    1412-1431               1452-1519         │
│    프랑스 군사 지도자       이탈리아 박학자     │
│    ★★★★★                  ★★★★★             │
│    🎮 Jeanne d'Arc         🎮 Da Vinci       │
│                                              │
│ 인물 클릭 → 생애 + 관련 사건 + 지구본 이동   │
└──────────────────────────────────────────────┘
```

### 경로 4: 서번트 입문 (TRISMEGISTUS — 통합 안내)

> TRISMEGISTUS는 Fate 세계관의 시스템 오케스트레이터. 여기서는 FGO↔역사 통합 안내.

**개념**: FGO 서번트 목록에서 출발, 실제 역사로 안내.

```
┌─ TRISMEGISTUS: 영령 기록 ────────────────────┐
│                                               │
│ "서번트의 진짜 역사를 관측합니다"               │
│                                               │
│ 클래스별:                                      │
│ [Saber] [Archer] [Lancer] [Rider] [Caster]   │
│ [Assassin] [Berserker] [Extra]               │
│                                               │
│ ⚔️ Saber 클래스                               │
│                                               │
│ 🗡️ Artoria Pendragon                          │
│    → 아서 왕 전설 · CE 500대 · 브리튼         │
│    "역사 속 아서 왕은..."                       │
│                          [역사 관측] [비교]   │
│                                               │
│ 🗡️ Siegfried                                  │
│    → 니벨룽겐의 노래 · CE 400대 · 게르만      │
│    "지크프리트의 전설은..."                     │
│                          [역사 관측] [비교]   │
│                                               │
│ [역사 관측] → 해당 시대+지역으로 지구본 이동   │
│ [비교] → FGO 설정 vs 실제 역사 비교 카드      │
└───────────────────────────────────────────────┘
```
