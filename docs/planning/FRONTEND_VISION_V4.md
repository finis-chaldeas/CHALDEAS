# Frontend Vision V4: 서사 중심 재설계

**작성일**: 2026-02-21
**핵심 전환**: 데이터 브라우저 → 서사 체험

---

## 왜 V4인가

V3까지의 프론트엔드 설계는 **데이터가 빈약한 세계**를 전제로 했다.
- event descriptions 평균 41자
- entity_narratives **0건**
- person descriptions 평균 32자
- period_narratives 대부분 llama3.1 저품질

그래서 UI 구조(탭, 모달, 사이드바)로 빈 콘텐츠를 보상하려 했다.
결과: 모달 6개, 탭 3개, 진입점 5개, 경로 2개 — 복잡하지만 보여줄 게 없다.

**2026-02-21, 상황이 바뀌었다.**

| 지표 | Before | After |
|------|--------|-------|
| entity_narratives (event) | 0건 | **2,332건** (평균 1,130자) |
| entity_narratives (person) | 0건 | **1,524건** (평균 1,582자) |
| event descriptions | 평균 41자 | **2,013건 평균 386자** |
| person descriptions | 평균 32자 | **1,520건 enriched** |
| period_narratives | llama 384건 | **GPT-5.1 391건** (평균 1,705자, 지역별 포함) |
| event_relationships (rich) | 0건 | **257건** (인과관계 설명) |

**이제 이야기가 있다.** UI 구조로 빈 공간을 채울 필요가 없다.
이야기 자체가 인터페이스가 된다.

## 핵심 전환: 3가지

### 1. 메타데이터 → 서사

**Before**: 카드에 `480 BCE · Thermopylae · Battle · ★★★★★` 표시
**After**: 카드에 "기원전 480년, 크세르크세스 1세가 이끄는 페르시아 대군이 테르모필레 협곡으로 진격했다. 스파르타의 왕 레오니다스 1세는 300명의 정예 전사를 이끌고 3일간 저항했다..." 표시

사용자가 보는 첫 번째 것은 **별점이 아니라 이야기**다.

### 2. 목록 → 맥락

**Before**: 사이드바에 이벤트 리스트 (피드 형태)
**After**: "지금 여기"의 시대 내러티브가 먼저, 그 안에 이벤트가 구조적으로 배치

"480 BCE, 지중해"를 보고 있으면:
> "축의 시대가 절정에 달한다. 그리스에서는 페르시아 전쟁이 벌어지고, 중국에서는 전국시대가 시작되며, 인도에서는 석가모니의 가르침이 퍼지고 있다."

이 문장 하나가 사이드바 탭 3개보다 낫다.

### 3. 탐색 → 흐름

**Before**: 클릭 → 상세 패널 → 닫기 → 다음 클릭
**After**: 인과관계를 따라 자연스럽게 흘러감

마라톤 → 테르모필레 → 살라미스 → 아테네 황금기.
각 전환마다 글로브가 움직이고, 새 서사가 펼쳐진다.
책장을 넘기듯.

## 레이아웃: Narrative Canvas (서사 캔버스)

### 기본 상태: 글로브 + 서사 오버레이

```
┌──────────────────────────────────────────────┐
│                                              │
│              G  L  O  B  E                   │
│              (전체 화면)                      │
│                                              │
│    ┌─ Context Strip ──────────────────┐      │
│    │ 480 BCE · Mediterranean          │      │
│    │ "페르시아 전쟁의 해. 그리스와     │      │
│    │  페르시아의 운명이 결정된다."     │      │
│    └──────────────────────────────────┘      │
│                                              │
│  ┌─ 🔍 ─┐                                   │
│  └──────┘                                   │
│                                              │
│  ════════════════════════════════════════    │
│  ← 3000 BCE ═══╋══════════════ 2026 CE →    │
│  ════════════════════════════════════════    │
└──────────────────────────────────────────────┘
```

- **글로브가 100% 화면**. 사이드바 없음.
- **Context Strip**: 현재 시간+장소의 1~2문장 서사 (period_narratives에서 추출). 글로브 위에 반투명 오버레이.
- **검색**: 좌측 상단 최소 아이콘.
- **타임라인 바**: 하단. 기존과 동일하되 더 슬림.
- 아무것도 안 누르면 글로브만 보인다.

### 마커 터치: Narrative Card (서사 카드)

```

│         │  세스 1세가 이끄는 페르시아    │   │
│         │  대군이 그리스 중부의 테르모   │   │

│         │                                │   │
│         │ ── 왜 중요한가 ──              │   │

│         │ → Salamis (480 BCE)            │   │
│         │   "테르모필레의 지연이 해군    │   │
│         │    준비 시간을 벌어줌"          │   │
│         │                                │   │
│         │ ── 인물 ──                     │   │
│         │ ○ Leonidas I  ○ Xerxes I      │   │
│         │                                │   │

```

**카드 구성** (위에서 아래로):
1. **제목 + 시공간** (기본 메타)
2. **서사** (entity_narratives.narrative — 150~250단어의 이야기)
3. **왜 중요한가** (entity_narratives.significance — 1문장)
4. **흐름** (event_relationships — 원인/결과, 각각 인과설명 포함)
5. **인물** (참여 인물 — 탭하면 인물 카드로)
6. **출처** (source attribution)

**핵심: 스크롤이 아닌 하나의 흐름으로 읽히는 카드.**
가장 중요한 것(이야기)이 가장 먼저 온다.

## 새로운 경험 1: World Briefing (세계 브리핑)

### 컨셉

글로브를 보고 있을 때, 현재 시간/장소의 **맥락을 즉시 제공**하는 반투명 오버레이.

391개 period_narratives(GPT-5.1, 평균 1,705자, 6개 지역별)에서 추출.

### 작동 방식

타임라인을 480 BCE에 놓고 지중해를 보고 있으면:

```
┌─ World Briefing ─────────────────────────────────┐
│                                                   │
│  480 ~ 431 BCE                                    │
│  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━       │
│                                                   │
│  "축의 시대가 절정에 달한다. 그리스에서는           │
│   페르시아 전쟁이 세계사의 흐름을 바꾸고,           │
│   아테네의 민주주의가 전성기를 맞는다."              │
│                                                   │
│  ── 이 지역 (유럽) ──                              │
│  "그리스-페르시아 전쟁의 결과로 아테네가             │
│   지중해 세계의 주도권을 잡는다. 페리클레스          │
│   치하에서 파르테논이 건설되고, 소크라테스가          │
│   아테네의 거리를 걸으며 철학을 논한다."             │
│                                                   │
│  ── 같은 시대, 다른 곳 ──                          │
│  동아시아: 전국시대 시작, 공자의 제자들 활동         │
│  남아시아: 석가모니 열반 직후, 불교 확산             │
│  근동: 페르시아 제국 최전성기에서 후퇴               │
│                                                   │
│  [열기]                                [닫기]     │
└───────────────────────────────────────────────────┘
```

**"같은 시대, 다른 곳"이 핵심 차별점.**
이것이 책이나 위키피디아로는 절대 줄 수 없는 경험.
Period Narratives의 regional breakdown이 이것을 가능하게 한다.

### 트리거

- 타임라인을 움직이면 자동 업데이트 (debounce 500ms)
- 글로브를 돌려서 다른 지역을 보면 해당 지역 narrative가 우선 표시
- Context Strip(1~2문장)은 항상 보이고, 탭하면 풀 브리핑으로 확장

## 새로운 경험 2: Causal Flow (인과 흐름)

### 컨셉

이벤트 간 인과관계를 **글로브 위에서 시각적으로 따라가는** 경험.
257개 enriched event_relationships의 인과 설명을 활용.

### 작동 방식

테르모필레 전투 카드에서 "→ Salamis" 를 누르면:

1. 글로브가 테르모필레 → 살라미스로 부드럽게 이동 (1.5초)
2. 이동 중에 인과설명이 페이드인:
   > "테르모필레에서의 3일간의 지연이 아테네 시민의 대피와 해군 집결 시간을 벌어주었다"
3. 살라미스 카드가 열리고, 또 다음 연결이 보인다
4. 계속 따라가면 인과관계의 사슬을 여행하게 된다

### 글로브 위 시각화

```
    Marathon ─────────→ Thermopylae ──────→ Salamis
    (490 BCE)           (480 BCE)            (480 BCE)
    마커 ●               마커 ●               마커 ●
         ╰── 인과 arc ───╯╰── 인과 arc ──────╯
```

- 인과관계 arc는 글로브 위에 곡선으로 표시
- arc 색상: 원인(주황) / 결과(청록)
- arc 위에 호버하면 인과 설명 tooltip

### 자동 흐름 모드 (Auto Flow)

"흐름 따라가기" 버튼을 누르면:
- 인과관계 사슬을 자동으로 따라감
- 3초마다 다음 이벤트로 이동
- 각 이벤트에서 핵심 서사 1~2문장 표시
- 다큐멘터리를 보는 듯한 경험

```
[▶ 흐름 따라가기]  [⏸ 일시정지]  [⏩ 건너뛰기]
```

## 새로운 경험 3: Parallel Worlds (평행 세계)

### 컨셉

**같은 시간, 다른 장소**에서 일어나고 있는 일을 대비해서 보여준다.
이것이 CHALDEAS만의 고유한 경험.

### 작동 방식

480 BCE 테르모필레를 보고 있을 때, 화면 하단에:

```
┌── 같은 시대의 세계 ──────────────────────────────┐
│                                                   │
│  ● 그리스                    ● 중국               │
│    페르시아 전쟁                전국시대 시작       │
│    테르모필레, 살라미스          오나라, 월나라 항쟁 │
│                                                   │
│  ● 인도                      ● 페르시아            │
│    석가모니 열반 직후            크세르크세스 원정   │
│    불교 첫 결집                 제국 최대 영토에서  │
│                                 후퇴 시작          │
│                                                   │
│  [●을 누르면 글로브가 해당 지역으로 이동]           │
└───────────────────────────────────────────────────┘
```

**핵심**: 테르모필레에서 그리스가 자유를 지키고 있을 때, 중국에서는 전국시대가, 인도에서는 불교가 퍼지고 있었다. 이 **동시성의 깨달음**이 CHALDEAS의 가장 강력한 훅이다.

### 데이터 소스

- period_narratives의 regional breakdown (6개 지역)
- events 테이블의 date_start 매칭
- persons 테이블의 birth/death year 매칭

- ← → 또는 스와이프로 이전/다음 정거장

### 기존 Story Modal과의 차이

기존 StoryModal은 이미 구현되어 있지만:
- 서사가 빈약했다 (description 41자)
- 이제 entity_narratives (1,582자)가 있어서 각 정거장이 풍부

**코드 변경**: StoryModal의 각 노드에 entity_narratives를 로드.
기존 코드를 거의 그대로 활용하되, 서사 데이터만 추가.

## 새로운 경험 5: Deep Read (깊이 읽기)

### 컨셉

글로브를 잠시 접고, **서사에 집중하는 읽기 모드**.

경로 B(독자)를 위한 경험이지만, V3의 타임라인/트리스메기스투스 같은 복잡한 모달 대신 **심플한 읽기 뷰**.

### 읽기 모드의 장점

1. **독자에게**: 글로브 없이 완결된 읽기 경험
2. **모바일에서**: 글로브 대신 이 모드가 기본
3. **콘텐츠 소비**: entity_narratives의 150~250단어 서사가 빛을 발함
4. **계층 탐색**: "이 사건의 위치" 트리에서 상위/하위 이벤트로 이동

## 새로운 경험 6: Time Lapse (타임랩스)

### 컨셉

**시간을 자동 재생하면서 글로브 위에 서사가 흐르는** 경험.
타임라인의 "재생" 버튼을 누르면 시작.

### 작동 방식

```
┌──────────────────────────────────────────────┐
│                                              │
│              G  L  O  B  E                   │
│              (전체 화면)                      │
│                                              │
│     마커들이 나타났다 사라짐                   │
│     영토가 변함 (옵션)                        │
│                                              │
│  ┌── Ticker ────────────────────────────┐    │
│  │ 480 BCE                              │    │
│  │ "테르모필레 전투 — 레오니다스의       │    │
│  │  300 스파르타인이 페르시아 대군에     │    │
│  │  맞서 싸우다"                        │    │
│  │                                      │    │
│  │ 479 BCE                              │    │
│  │ "플라타이아 전투 — 그리스 연합군의   │    │
│  │  결정적 승리"                        │    │
│  └──────────────────────────────────────┘    │
│                                              │
│  [⏸]  ←══════════╋═══════════→  [속도: 2x]  │
│         3000 BCE    480 BCE    2026 CE       │
└──────────────────────────────────────────────┘
```

- 10년/초 ~ 100년/초 속도 조절
- 중요 이벤트(importance ≥ 4)만 Ticker에 표시
- Period가 바뀔 때마다 World Briefing 자동 업데이트
- 특정 지역에 줌인한 상태면 해당 지역 이벤트만 표시
- 아무 곳이나 터치하면 일시정지 + 해당 이벤트 카드 열기

## 네비게이션: Hub & Spoke

### 모든 것의 중심은 글로브

```
                    ┌─────────┐
                    │ 글로브   │
                    │ (허브)   │
                    └────┬────┘
                         │
            ┌────────────┼────────────┐
            │            │            │
       ┌────┴────┐  ┌────┴────┐  ┌───┴────┐
       │Narrative │  │ Person  │  │ Deep   │
       │  Card    │  │ Journey │  │ Read   │
       │(스포크1) │  │(스포크2)│  │(스포크3)│
       └─────────┘  └─────────┘  └────────┘
```

- **글로브에서 출발**: 마커 터치 → Narrative Card
- **카드에서 인물**: 인물 터치 → Person Journey
- **카드에서 읽기**: "깊이 읽기" → Deep Read
- **어디서든 글로브로**: "글로브에서 보기" → 글로브 해당 위치로 복귀

**모달 0개.** 전체 화면 전환이 아니라 **카드의 전환**으로 표현.

### 뒤로가기 스택

```
글로브 → Thermopylae Card → Leonidas Card → Deep Read
  ←            ←                ←               ←
```

브라우저 히스토리처럼 ← 버튼으로 이전 화면 복귀.
항상 글로브가 스택의 바닥에 있다.

## 모바일 경험

### 핵심 차이

모바일에서 글로브는 작다. 터치 정밀도가 낮다.

**해결**: 모바일 기본 뷰는 **Deep Read + 미니 글로브**.

```
┌──────────────────────┐
│  ● ← [미니 글로브]    │
│  지중해 · 480 BCE     │
├──────────────────────┤
│                      │
│  World Briefing      │
│  "축의 시대가 절정에  │
│   달한다..."         │
│                      │
│  ── 주요 사건 ──     │
│                      │
│  ● Thermopylae       │
│    "300 스파르타인    │
│     의 최후의 저항"   │
│                      │
│  ● Salamis           │
│    "테미스토클레스의  │
│     결정적 해전"      │
│                      │
│  ── 주요 인물 ──     │
│                      │
│  ○ Leonidas I        │
│  ○ Xerxes I          │
│  ○ Themistocles      │
│                      │
└──────────────────────┘
```

상단의 미니 글로브를 탭하면 전체 화면 글로브로 확장.
기본은 리스트/카드 뷰 (서사 중심).
