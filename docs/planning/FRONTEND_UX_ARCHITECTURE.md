# CHALDEAS 프론트엔드 UX 설계

## 이 앱이 주는 경험

CHALDEAS는 **지구본을 돌리면서 역사를 탐험하는 앱**이다.

사용자는 3D 지구본 위에서 시간 슬라이더를 움직이고, 마커를 클릭하고, 인물과 사건을 따라가며 역사를 "여행"한다. FGO(Fate/Grand Order)의 칼데아 시스템에서 영감을 받았기 때문에, 단순한 백과사전이 아니라 **관측소에서 인류사를 내려다보는 느낌**을 준다.

---

## 화면의 세 영역

화면은 항상 세 영역으로 나뉜다:

```
┌─ 왼쪽 ──────┬──── 가운데 ─────┬── 오른쪽 ──┐
│ "어디로 갈까" │  "지금 보는 것"  │ "자세히"   │
│              │                 │            │
│ 목적지 선택   │  3D 지구본       │ 선택한 것의 │
│ 검색          │  시간 슬라이더    │ 상세 정보   │
│ 브라우징      │                 │            │
└──────────────┴─────────────────┴────────────┘
```

- **왼쪽 사이드바**: "다음에 뭘 볼까?"를 결정하는 곳. 목록을 훑고 클릭한다.
- **가운데 지구본**: 현재 보고 있는 시공간. 여기가 앱의 본체다.
- **오른쪽 패널**: 클릭한 사건/인물/장소의 상세. 읽는 공간이다.

이 세 영역의 역할은 절대 섞이지 않는다.

---

## 사이드바: "다음 목적지" 고르기

사이드바는 320px로 좁다. 의도적이다. 여기는 **읽는 곳이 아니라 고르는 곳**이기 때문이다.

### 세 개의 탭

| 탭 | 뭘 보여주는가 | 사용자의 질문 |
|---|---|---|
| **Events** | 지금 시간대의 사건+인물 피드 | "이 시대에 무슨 일이 있었지?" |
| **People** | 지금 시간대의 인물 목록 | "이 시대에 누가 살았지?" |
| **Places** | 지금 보이는 장소 목록 | "이 지역에 뭐가 있지?" |

세 탭 모두 **지구본과 연동**된다. 지구본을 유럽 쪽으로 돌리면 유럽의 사건/인물/장소가 뜨고, 시간 슬라이더를 500 BCE로 옮기면 그 시대 것들이 뜬다. 목록에서 아무거나 클릭하면 지구본이 그쪽으로 날아가고 오른쪽에 상세가 열린다.

### Interest / Expert 모드

같은 탭이지만 보여주는 깊이가 다르다:

- **Interest** (캐주얼): "뭘 봐야 할지 모르겠어요" → 큐레이션된 추천 카드. 넷플릭스처럼 "이거 한번 보세요" 식.
- **Expert** (탐색): "내가 찾겠어요" → 전체 데이터, 검색, 정렬, 필터. 위키피디아처럼 직접 파고들기.

처음 오는 사람은 Interest에서 추천을 따라가다가, 익숙해지면 Expert로 바꿔서 직접 탐색한다.

## 두 개의 모달 버튼: "더 깊이 들어가기"

사이드바 상단에 두 개의 버튼이 있다:

```
┌──────────────────────────┐
│ [⏳ Timeline]  [✦ FGO]   │
└──────────────────────────┘
```

이 버튼들은 탭이 아니다. **별도의 풀스크린 화면을 여는 문**이다.

왜 탭이 아닌가? 이 콘텐츠들은 320px에 넣으면 망가지기 때문이다:

### ⏳ Timeline — "시대를 읽다"

Timeline 버튼을 누르면 화면 전체를 덮는 모달이 열린다.

```
┌── 왼쪽: 시대 목차 ──┬── 오른쪽: 선택한 시대의 이야기 ──────────────┐
│                     │                                              │
│ ▼ 고대              │  기원전 600~551년                             │
│ ▼ 고전              │  "축의 시대가 시작되다"                        │
│   ▸ -600~-551  ◀──│──│                                             │
│   ▸ -550~-501      │  이 반세기 동안 그리스에서는 폴리스가...        │
│ ▸ 중세              │                                              │
│ ▸ 근대              │  ┌─ 유럽 & 지중해 ──────────────────────┐    │
│                     │  │ 그리스 도시국가의 부상                  │    │
│                     │  │ "너 자신을 알라" — 델포이 신탁          │    │
│                     │  └──────────────────────────────────────┘    │
│                     │                                              │
│                     │  주요 사건:                                   │
│                     │   ⚔ 테르모필레 전투 (480 BCE)  [→ 지구본]     │
│                     │                                              │
│                     │  주요 인물:                                   │
│                     │   키루스 대왕 | 공자 | 석가모니               │
└─────────────────────┴──────────────────────────────────────────────┘
```

이것은 **역사책의 목차를 펼치는 경험**이다. 왼쪽에서 시대를 고르고, 오른쪽에서 그 시대의 이야기를 읽는다. 지역별 카드가 있고, 인용문이 있고, 그 시대를 정의한 사건과 인물 목록이 있다.

여기서 사건이나 인물을 클릭하면? 모달이 닫히고, 지구본이 그 장소로 날아가고, 오른쪽에 상세 패널이 열린다. **책에서 지도로 전환되는 순간**이다.

### ✦ FGO — "게임과 역사의 접점"

FGO 버튼을 누르면 Fate/Grand Order의 특이점(Singularity), 이문대(Lostbelt), 서번트 정보를 탐색할 수 있다. 게임 팬이 "이 캐릭터의 실제 역사가 뭐지?"라는 궁금증에서 시작하여 실제 역사로 넘어가는 **다리** 역할을 한다.

메뉴에서 항목을 고르면 상세 설명이 나오고, 거기서 "관련 이벤트"를 클릭하면 역시 지구본으로 돌아간다. 서번트 브라우저에서 인물을 클릭하면 그 인물의 실제 역사적 기록으로 연결된다.

**핵심**: 어떤 경로로 들어오든 최종 목적지는 항상 **지구본 위의 시공간**이다.

## 모든 길은 지구본으로 통한다

이 앱의 모든 인터랙션은 하나의 패턴을 따른다:

```
탐색 (사이드바/모달)
  → 선택 (클릭)
    → 지구본 이동 (fly-to)
      → 상세 확인 (우측 패널)
        → 관련 항목 탐색 (다시 처음으로)
```

어디서 시작하든 — Events 탭에서든, Timeline 모달에서든, FGO 아카이브에서든, 검색창에서든 — 클릭하면 지구본이 움직이고, 상세가 열린다. 그 상세 안에서 다른 사건이나 인물을 클릭하면 또 지구본이 움직인다. 이 순환이 **"역사 여행"의 느낌**을 만든다.

## 요약: 세 가지 탐험 모드

| 모드 | 진입 | 경험 | 비유 |
|------|------|------|------|
| **브라우징** | 사이드바 3탭 | 목록 훑으며 흥미로운 거 골라 클릭 | 박물관에서 전시실 돌아다니기 |
| **시대 읽기** | Timeline 버튼 | 시대별 내러티브를 읽고, 사건/인물로 점프 | 역사책 목차에서 관심 가는 장 펼치기 |
| **게임 연결** | FGO 버튼 | 게임 콘텐츠에서 실제 역사로 건너가기 | 게임 위키에서 "실제 역사" 링크 클릭 |

세 모드 모두 최종 도착지는 **지구본 위의 한 지점, 한 시간**이다.
