## 왜 콘텐츠가 먼저인가

UI를 아무리 잘 만들어도 보여줄 이야기가 없으면 빈 껍데기다. 지금 상태:
- SHEBA 에피소드: 16개 (tourSteps 있는 건 6개)
- Period Narratives: 89개 중 7개만
- Domain Stories: 0개
- Person Stories (큐레이션): 0개

**콘텐츠를 먼저 만들고, UI를 거기에 맞추는 게 순서다.**

## 제작 파이프라인

### Step 1: 나무위키 구조 분석

백년전쟁을 예로:

```
나무위키 "백년전쟁" 항목 구조:
1. 개요
2. 배경
   2.1. 왕위 계승 문제
   2.2. 영토 분쟁 (아키텐)
3. 전쟁의 경과
   3.1. 1차 시기 (에드워드 전쟁, 1337~1360)
      - 크레시 전투 (1346)
      - 흑사병 (1347)
      - 푸아티에 전투 (1356)
      - 브레티니 조약 (1360)
   3.2. 2차 시기 (카롤린 전쟁, 1369~1389)
      - 프랑스 반격
      - 게릴라전
   3.3. 3차 시기 (랑카스터 전쟁, 1415~1453)
      - 아쟁쿠르 전투 (1415)
      - 잔 다르크 (1429~1431)
      - 프랑스 최종 승리 (1453)
4. 결과와 영향
```

### Step 2: GPT-5.1 프롬프트

```
당신은 고등학생을 대상으로 한 역사 콘텐츠 작성자입니다.

아래 나무위키 항목의 구조를 참고하여, CHALDEAS 역사 관측 시스템용
가이드 투어 에피소드를 작성해주세요.

[참고 항목]: 백년전쟁 (나무위키)
[핵심 구조]: 1337~1453, 영국 vs 프랑스, 3단계 진행

작성 규칙:
1. 각 스텝은 극적인 순간을 포착합니다 (전투, 회담, 사건)
2. 설명은 2~3문장, 고등학생이 "와 재미있다" 할 수준
3. 각 스텝에 정확한 위도/경도를 포함합니다
4. 한국어 제목 + 영어 제목 병기
5. 전체 5~8 스텝으로 구성

출력 형식: JSON (ShebaEpisode 형식)
```

### Step 3: 인간 검수

- 날짜/위치 정확성 확인
- 나무위키와 대조해서 빠진 핵심 사건 보충
- 서술 톤이 고등학생 타겟에 맞는지 확인
- DB 엔티티(events, persons)와 매핑

### Step 4: 데이터 저장

**방식 A** (당장): `shebaEpisodes.ts`에 직접 추가 (현재 방식)
**방식 B** (추후): DB 테이블 `curated_episodes` + API `/curated/episodes`

50개까지는 방식 A로 충분. 100개 이상이면 방식 B로 전환.

## 나무위키 활용 방법

### 참고할 항목 특징

나무위키의 역사 항목은:
1. **연대순 정리**가 잘 되어 있다 → tourSteps 순서
2. **"여담"/"기타" 섹션**에 재미있는 일화가 있다 → description에 활용
3. **관련 인물 링크**가 잘 되어 있다 → relatedServants에 활용
4. **전투/사건별 독립 항목**이 있다 → 각 tourStep의 디테일

### 주의점

1. **나무위키를 복사하지 않는다** — 구조와 사실만 참고, 서술은 GPT로 새로 작성
2. **검증이 필요한 정보는 Wikipedia 대조** — 나무위키는 오류가 있을 수 있음
3. **날짜/위치는 별도 확인** — 위도/경도는 Google Maps에서 확인

### 프롬프트 전략

```
# GPT-5.1 프롬프트 템플릿

역할: 고등학생 대상 역사 콘텐츠 작성자
```

## ShebaEpisode 스키마 확장 (제안)

현재 스키마에 추가할 필드:

```typescript
export interface ShebaEpisode {
  // ... 기존 필드 ...

  // 신규 필드 (선택)
  tags?: string[]           // 검색/필터용: ['war', 'medieval', 'europe']
  contentType?: 'event' | 'domain' | 'person'  // 에피소드 종류
  difficulty?: 'beginner' | 'intermediate' | 'advanced'  // 난이도
  readTime?: number         // 예상 읽기 시간 (분)
  prerequisites?: string[]  // 먼저 읽으면 좋은 에피소드 id
  followUp?: string[]       // 다음에 읽을 에피소드 id
  namuRef?: string          // 나무위키 참고 항목명
}
```

`prerequisites` / `followUp`으로 에피소드 간 연결이 가능해진다:
- 백년전쟁 → followUp: ['ep-joan-hundred']
- 알렉산더 동방원정 → prerequisites: ['ep-persian-empire']
- 과학혁명 → followUp: ['ep-industrial-revolution']
