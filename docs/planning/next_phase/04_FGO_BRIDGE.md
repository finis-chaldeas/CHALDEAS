# 04. 서번트 ↔ 역사 브릿지 (TRISMEGISTUS)

> TRISMEGISTUS는 관측 시스템의 오케스트레이터. 여기서는 **게임 캐릭터와 실제 역사를 연결**하는 통합 안내 시스템.

---

## 핵심 철학

**FGO 오타쿠는 역사를 모르지만, 서번트는 안다.**
이 친숙한 캐릭터를 입구 삼아 "실제 역사가 이런 거였어?" 하는 경험을 만든다.

```
길가메시(Archer) ──→ "이 캐릭터의 진짜 역사"
                      ├─ 역사적 배경: 수메르 우루크의 왕 (BCE 2700경)
                      ├─ 관련 사건: 길가메시 서사시, 우루크 건설
                      ├─ 관련 장소: 우루크, 메소포타미아
                      └─ [이 시대 탐색] → 지구본이 메소포타미아로 이동
```

---

## 서번트 분류 체계

게임 캐릭터는 4가지 유형으로 분류되며, 각 유형별 역사 연결 방식이 다르다:

| 유형 | 설명 | 예시 | 연결 방식 |
|------|------|------|----------|
| **Historical** | 실존 인물 | 레오니다스, 카이사르, 네로 | Person 1:1 매칭 |
| **Legendary** | 전설/신화 인물 | 길가메시, 아서왕, 쿠 훌린 | Person (certainty: legendary) + 원전 소스 |
| **Divine** | 신격 | 이슈타르, 케찰코아틀 | 신화 체계 연결 |
| **Fictional** | 가공/복합 인물 | 셜록 홈즈, 프랑켄슈타인 | 원작 텍스트 연결 |

## 멀티버스 데이터 구조

역사 데이터와 게임 데이터를 **연결하되 격리**:

```
┌─────────────────────────────────────────────────────┐
│  LAYER 1: Historical (Canonical)  universe_id = 1    │
│  - Wikidata QID 연동                                 │
│  - Wikipedia/책 기반                                  │
│  - 학술적으로 검증 가능                               │
└───────────────────────┬─────────────────────────────┘
                        │ canonical_id 참조
                        ▼
┌─────────────────────────────────────────────────────┐
│  LAYER 2: FGO (Fictional)  universe_id = 2           │
│  - servant_profiles (클래스, 보구, 레어도)            │
│  - Atlas Academy 연동                                │
│  - TYPE-MOON 세계관 해석                              │
└─────────────────────────────────────────────────────┘
```

### DB 구조

```sql
-- 세계관 테이블
CREATE TABLE universes (
    id SERIAL PRIMARY KEY,
    code VARCHAR(30) UNIQUE NOT NULL,  -- 'historical', 'fgo'
    name VARCHAR(100) NOT NULL,
    is_canonical BOOLEAN DEFAULT FALSE,
    color VARCHAR(7)  -- UI 색상
);

-- persons 확장
ALTER TABLE persons ADD COLUMN universe_id INTEGER DEFAULT 1;
ALTER TABLE persons ADD COLUMN canonical_id INTEGER REFERENCES persons(id);
-- Historical Joan: id=100, universe_id=1, canonical_id=NULL
-- FGO Ruler:       id=2001, universe_id=2, canonical_id=100
-- FGO Alter:       id=2002, universe_id=2, canonical_id=100

-- 서번트 프로필 (FGO 전용)
CREATE TABLE servant_profiles (
    id SERIAL PRIMARY KEY,
    person_id INTEGER REFERENCES persons(id),
    servant_class VARCHAR(50),
    rarity INTEGER,
    noble_phantasm_name VARCHAR(200),
    origin_type VARCHAR(50),  -- historical, legendary, divine, fictional
    atlas_id INTEGER,
    historical_fact TEXT,
    fate_interpretation TEXT
);
```

### API 설계

```
GET /api/v1/persons?universe=historical  # 역사만 (기본)
GET /api/v1/persons?universe=fgo         # 서번트만
GET /api/v1/persons/{id}/variants        # 모든 버전 (역사 + FGO 파생)
GET /api/v1/servants?class=Saber         # 서번트 목록
GET /api/v1/servants/{id}/profile        # 서번트 상세
GET /api/v1/servants/{id}/compare        # 게임 vs 역사 비교
```

## 페르소나 시스템 (내러티브)

역사 설명을 여러 톤으로 제공:

| 페르소나 | 톤 | 말투 | 특징 |
|----------|-----|------|------|
| **Official** | 다큐멘터리 | 격식체 | 기본값, 정확하고 객관적 |
| **Mash** | 따뜻하고 친근 | 해요체 | 선배를 안내하듯 |
| **Leonardo** | 자신감/장난기 | 반말 | 천재적 통찰 |

```
[Official]
"1429년 4월 29일, 잔 다르크는 4천 명의 병사를 이끌고
오를레앙에 입성하였다. 7개월간의 영국군 포위가 9일 만에 풀렸고,
이는 백년전쟁의 결정적 전환점이 되었다."

[Mash]
"선배, 이곳이 오를레앙이에요. 1429년 4월, 잔 다르크가 도착했을 때
이 도시는 이미 7개월째 포위되어 있었어요. 단 9일 만에
포위가 풀렸다니, 정말 기적 같은 일이죠?"

[Leonardo]
"잔 다르크? 흥미로운 소녀지. 17살에 군대를 이끌고
포위된 도시를 9일 만에 해방시켰다고? 천재적이야.
...그래, 나보다는 좀 부족하지만."
```

**생성 방식**: On-demand (요청 시 LLM 생성 → DB 캐싱)
**비용**: gpt-5-nano 기준 ~$0.01/인물

## 추천 에피소드에서의 서번트 활용

SHEBA 추천 에피소드(03_FEED_UX.md)에 서번트를 자연스럽게 포함:

```
┌─ SHEBA: 추천 관측 ───────────────────────────────┐
│                                                    │
│ 📖 잔 다르크와 백년전쟁                             │
│    1337-1453 · 프랑스/잉글랜드                     │
│    "한 소녀가 나라를 구한 이야기"                   │
│                                                    │
│    등장 영령:                                      │
│    🎮 Jeanne d'Arc (Ruler ★★★★★)                  │
│    🎮 Gilles de Rais (Caster ★★★)                 │
│                                                    │
│    주요 사건 8개 · 원전: 오를레앙 포위전 일지      │
│                                  [관측 시작]        │
└────────────────────────────────────────────────────┘
```

**[관측 시작] 클릭 시:**
1. 지구본이 프랑스 지역으로 이동
2. 타임라인이 1337-1453으로 설정
3. Feed에 백년전쟁 주요 사건이 순서대로 표시
4. 서번트 관련 사건에 🎮 아이콘 표시
5. 잔 다르크의 이동 경로가 지구본에 아크로 표시
   (도므레미 → 시농 → 오를레앙 → 파테 → 랭스 → 콩피에뉴 → 루앙)

## 구현 단계

### Phase 1: 기본 서번트 목록 + 역사 연결 (기존 데이터 활용)
- `servants.json` 확장 (현재 2개 → 100개+)
- 서번트 → Person canonical 매핑 (수동 + 자동)
- 서번트 패널에 [역사 관측] 버튼 → globeStore.setYear + setViewport
