# 줌은 확대가 아니다. 서사의 해상도다.

## 핵심

지구본을 확대하면 같은 것이 커지는 게 아니다.
**다른 이야기가 나타난다.**

이것이 CHALDEAS의 가장 핵심적인 인터랙션이다.
이것이 구글 맵과 다른 점이다.
이것이 위키피디아와 다른 점이다.

---

## 네 단계

### 1단계: COSMIC (가장 멀리, 지구 전체)

**유저가 보는 것:**
- 지구 전체
- 대륙별로 2~3개의 큰 원 (이 시대에 문명이 있는 곳)
- 각 원 위에 이름: "Classical Greece", "Warring States", "Maurya Empire"
- 원의 크기 = 이 시대 이벤트의 밀도
- 원끼리 연결선 = 문명 간 교류 (실크로드, 해상 무역)

**유저가 느끼는 것:**
"아, 이 시대에 세계는 이렇게 생겼구나. 여기는 뭔가 많이 일어나고 있고, 저기는 조용하네."

**유저가 할 수 있는 것:**
- 원을 클릭 → 해당 문명권으로 줌인 (2단계로)
- 타임라인을 움직임 → 원들이 나타났다 사라짐 (문명의 흥망)

**데이터 수준:**
- `temporal_scale = 'longue_duree'` 이벤트만 표시
- `hierarchy_level = 1` (최상위 이벤트만)
- 영토 오버레이: 대제국 단위
- 개별 인물은 보이지 않음

**타임라인 바:**
시대 이름만 보임 (Ancient / Classical / Medieval / Early Modern / Modern)

---

### 2단계: CONTINENTAL (대륙/지역권)

**유저가 보는 것:**
- 지중해 전체, 또는 동아시아 전체
- 이벤트 클러스터가 보임 (아직 개별 마커는 아님)
- 클러스터 위에 이름: "Greco-Persian Wars", "Rise of Athens"
- 영토 오버레이: 페르시아=빨강, 그리스 도시국가=파랑 점
- 주요 인물 아이콘이 클러스터 근처에 나타남

**유저가 느끼는 것:**
"이 지역에서 이 시대에 이런 일들이 일어났구나. 페르시아가 이렇게 컸어?"

**유저가 할 수 있는 것:**
- 클러스터 클릭 → 컨텍스트 서랍 열림 (사건 목록, 주요 인물, 시대 설명)
- 영토 클릭 → 영토 정보 카드
- 인물 아이콘 클릭 → 인물 카드

**데이터 수준:**
- `temporal_scale = 'conjuncture'` + `'longue_duree'`
- `hierarchy_level <= 2`
- `is_aggregate = true` 이벤트 위주
- 영토 오버레이: 제국/왕국 단위
- `importance >= 4` 인물만

**타임라인 바:**
50년 단위 마디, 각 마디에 이벤트 밀도 히트맵

---

### 3단계: REGIONAL (국가/지역)

**유저가 보는 것:**
- 그리스 본토가 화면을 채움
- **개별** 이벤트 마커가 보임 (클러스터 해제)
- 각 마커 옆에 이름: "Thermopylae", "Salamis", "Plataea"
- 마커 크기 = importance
- 마커 색상 = 카테고리 (전투=빨강, 정치=파랑, 문화=노랑)
- 마커 사이에 화살표: Thermopylae → Salamis → Plataea (인과관계)
- 인물 아이콘이 마커 위에 붙어있음

**유저가 느끼는 것:**
"여기서 이 순서로 전투가 벌어졌구나. 이 사람이 여기 있었구나."

**유저가 할 수 있는 것:**
- 마커 클릭 → 이벤트 카드 (상세 정보, 인과관계, 참여 인물)
- 인물 아이콘 클릭 → 인물 카드 (생애, 관계, 이 장소에서의 역할)
- 화살표 따라가기 → 지구본이 다음 이벤트 위치로 날아감

**데이터 수준:**
- `temporal_scale = 'evenementielle'` 포함 (모든 스케일)
- `hierarchy_level <= 3`
- 개별 이벤트 표시 (is_aggregate 관계없이)
- `event_relationships` 화살표 표시
- `person_relationships` 인물 간 관계선
- 영토 오버레이: 도시국가/소왕국 단위

**타임라인 바:**
10년 또는 연 단위, 이벤트 개별 점 표시

---

### 4단계: LOCAL (도시/전장 수준)

**유저가 보는 것:**
- 테르모필레 협곡이 화면에 가득 참
- **하위 이벤트** 마커: "Day 1: Initial Defense", "Day 2: Betrayal", "Day 3: Last Stand"
- 마커를 시간순으로 연결하는 점선
- 지형이 자세히 보임
- 참여 인물 전원의 아이콘

**유저가 느끼는 것:**
"이 좁은 협곡에서 3일 동안 이런 일이 벌어졌구나."

**유저가 할 수 있는 것:**
- 하위 이벤트 마커 클릭 → 세부 이벤트 카드
- 시간순 점선을 따라 자동 재생
- 인물별 시점으로 전환

**데이터 수준:**
- `parent_event_id` 기반 하위 이벤트 표시
- `hierarchy_level = 3~4` (최하위)
- 모든 인물 표시 (importance 무관)
- 이벤트 내 역할(role) 표시: "지휘관", "침략자", "배신자"

**타임라인 바:**
일/주 단위까지 내려감

---

## 왜 이것이 본질인가

줌 레벨에 따라 데이터가 달라지지 않으면,
지구본은 그냥 예쁜 지도에 불과하다.

줌이 서사의 해상도가 되려면:
1. **이벤트에 계층이 있어야 한다** (전쟁 → 전투 → 전투의 하루)
2. **이벤트에 시간 스케일이 있어야 한다** (longue_duree, conjuncture, evenementielle)
3. **인물에 중요도가 있어야 한다** (멀리서는 알렉산더만, 가까이 가면 부하 장군들도)
4. **영토에 시간 범위가 있어야 한다** (480 BCE의 페르시아 영토 ≠ 400 BCE의 페르시아 영토)
5. **이벤트 간 인과관계가 있어야 한다** (화살표로 "왜?"와 "그래서?"를 보여주려면)

이 모든 것이 DB에 이미 설계되어 있다.
`hierarchy_level`, `temporal_scale`, `importance`, `territory_locations.valid_from/until`, `event_relationships`.

**문제는 프론트엔드가 이것을 활용하지 않고 있다는 것이다.**
모든 줌 레벨에서 같은 마커를 보여주고 있다.
이것이 바꿔야 할 가장 핵심적인 것이다.
