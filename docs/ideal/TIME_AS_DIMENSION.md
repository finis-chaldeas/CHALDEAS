# 시간은 필터가 아니다. 세계의 또 하나의 차원이다.

## 핵심

시간을 움직이면 세계가 변한다.
마커만 바뀌는 게 아니다. **세계 자체가** 변한다.

---

## 시간이 바꾸는 것들

타임라인을 480 BCE → 400 BCE → 330 BCE → 200 BCE로 드래그하면:

### 1. 영토가 숨 쉰다

```
480 BCE: 페르시아 제국이 이집트에서 인도까지 거대한 빨간 영역
400 BCE: 페르시아가 약간 줄어듦, 그리스 도시국가들이 분열
330 BCE: 페르시아 영역이 사라지고, 알렉산더 제국이 같은 영역을 차지 (색 변경)
200 BCE: 알렉산더 제국이 셀레우코스/프톨레마이오스/마케도니아로 분열
```

영토 오버레이가 시간에 따라 변한다. 제국이 커졌다 작아졌다 한다.
이것은 `territories` 테이블의 `founded_year`/`dissolved_year`와
`territory_locations`의 `valid_from`/`valid_until`로 구현된다.

### 2. 마커가 나타나고 사라진다

480 BCE에 있던 "테르모필레 전투" 마커는 400 BCE에서 희미해지고,
대신 "펠로폰네소스 전쟁" 마커가 나타난다.

이벤트의 `date_start`/`date_end`가 현재 시간 범위와 겹치면 보이고, 아니면 사라진다.

### 3. 인물이 바뀐다

480 BCE: 레오니다스, 크세르크세스, 테미스토클레스
400 BCE: 소크라테스, 페리클레스, 투키디데스
330 BCE: 알렉산더, 아리스토텔레스, 다리우스 3세

인물의 `birth_year`/`death_year`(또는 `floruit_start`/`floruit_end`)가
현재 시간에 맞는 인물만 표시된다.

### 4. 장소 이름이 바뀐다

```
667 BCE: Byzantium
  330 CE: Constantinople (로마 제국 수도 이전)
 1930 CE: Istanbul (터키 공화국)
```

같은 좌표, 같은 점. 하지만 시간을 움직이면 이름이 바뀐다.
`location_names` 테이블의 `valid_from`/`valid_until`로 구현된다.

### 5. 시대 분위기가 바뀐다

타임라인 상단에 "NOW OBSERVING" 배너가 있다:
```
480 BCE: "페르시아 전쟁의 절정기. 동서 문명의 충돌."
400 BCE: "아테네의 황금기가 저물고, 그리스가 분열한다."
330 BCE: "알렉산더가 세계를 정복하고, 헬레니즘이 시작된다."
```

`period_narratives` 테이블의 50년 단위 내러티브가 자동으로 바뀐다.

## 시간의 세 가지 속도 (브로델의 시간론)

같은 시간 범위를 봐도, 어떤 속도로 보느냐에 따라 다른 것이 보인다.

### evenementielle (단기: 일~년)
개별 사건. 전투, 조약, 암살, 연설.
"480년 8월, 테르모필레에서 300명이 죽었다."

### conjuncture (중기: 수십 년)
추세와 운동. 전쟁, 왕조, 혁명, 학파.
"기원전 5세기, 그리스와 페르시아의 패권 경쟁이 지중해를 뒤흔들었다."

### longue durée (장기: 수백 년)
구조와 문명. 기후, 지리, 제국, 종교.
"지중해 무역 네트워크가 고전 문명의 기반이 되었다."

이 세 속도는 DB의 `events.temporal_scale` 컬럼에 저장된다.
줌 레벨과 조합하면:

| 줌 | 시간 속도 | 보이는 것 |
|----|----------|----------|
| COSMIC | longue durée | 문명의 흥망 |
| CONTINENTAL | conjuncture | 전쟁과 운동 |
| REGIONAL | evenementielle | 개별 전투와 사건 |
| LOCAL | evenementielle | 사건의 하루하루 |

## 시간 재생

타임라인의 재생 버튼을 누르면, 시간이 자동으로 흐른다.
속도를 조절할 수 있다 (10년/초, 50년/초, 100년/초).

지구본 위에서:
- 마커가 나타났다 사라진다
- 영토가 커졌다 줄어든다
- 인물 아이콘이 등장했다 퇴장한다
- 장소 이름이 바뀐다

**유저는 역사가 흘러가는 것을 눈으로 본다.**
이것이 "시간여행"의 본질이다.

---

## 시간은 왜 차원인가

필터는 "이것만 보여줘"다. 차원은 "세계가 달라져"다.

연도를 바꾸면:
- 단순히 다른 데이터가 쿼리되는 게 아니다
- **세계의 상태 자체가** 바뀐다
- 영토의 경계가 바뀌고
- 장소의 이름이 바뀌고
- 살아있는 사람이 바뀌고
- 일어나고 있는 사건이 바뀐다

이것이 CHALDEAS가 가진 모든 테이블에 `valid_from`/`valid_until` 패턴이 반복되는 이유다:
- `location_names`: 장소 이름의 시간 범위
- `territory_locations`: 영토 소속의 시간 범위
- `person_relationships`: 관계의 시간 범위
- `person_names`: 인물 이름의 시간 범위

**모든 것은 시간 안에서만 존재한다.**
