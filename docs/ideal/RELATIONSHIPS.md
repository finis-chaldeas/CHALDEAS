# 사람과 사람, 사건과 사건은 선으로 연결된다

## 핵심

고립된 사실은 의미가 없다.
"소크라테스가 399 BCE에 죽었다" — 그래서?

"소크라테스의 **제자** 플라톤이, 스승의 죽음에 충격을 받아 아카데미아를 세웠고, 그 아카데미아의 **제자** 아리스토텔레스가 알렉산더 대왕의 **스승**이 되어 헬레니즘 세계의 지적 토대를 놓았다."

이것이 의미다. 의미는 연결에서 나온다.

---

## 세 종류의 연결

### 1. 인물 간 관계 (person_relationships)

사람과 사람은 관계로 이어진다:
- **teacher/student**: 소크라테스 → 플라톤 → 아리스토텔레스
- **rival**: 아테네 ↔ 스파르타의 지도자들
- **ally**: 레오니다스 — 테미스토클레스
- **family**: 알렉산더 — 필리포스 2세 (부자)
- **patron/protégé**: 페리클레스 — 피디아스

각 관계에는:
- **strength** (1-5): 얼마나 깊은 관계인가
- **valid_from/until**: 언제부터 언제까지 이 관계가 유효한가
- **bidirectional**: 쌍방인가 단방향인가

**유저 경험:**
인물 카드에서 관계를 보면, 단순 목록이 아니라 **네트워크**가 보인다.
소크라테스를 중심으로 제자들이 방사형으로 뻗어나가고,
각 선의 굵기가 관계의 강도를 보여주고,
색상이 관계의 종류를 보여준다.

선을 따라가면 → 다른 인물 카드로.
그 인물의 생애를 보면 → 지구본 위 다른 장소로.

### 2. 사건 간 인과관계 (event_relationships)

사건과 사건은 원인과 결과로 이어진다:
- **causes**: 마라톤 전투 → 테르모필레 전투 (페르시아의 2차 침공)
- **enables**: 알렉산더의 정복 → 헬레니즘 문화 확산
- **follows**: 페리클레스 사망 → 아테네 쇠퇴
- **opposes**: 아테네 민주주의 ↔ 스파르타 과두정

각 관계에는:
- **certainty**: certain / probable / possible / disputed
- **evidence_type**: primary_source / scholarly_consensus / inference / tradition
- **strength** (1-5): 인과관계의 강도

**유저 경험:**
이벤트 카드에서 "왜 이 일이 일어났는가?" 섹션이 보인다.
```
← 원인: Battle of Marathon (490 BCE)
         "페르시아의 1차 침공 실패가 크세르크세스의 복수 원정을 야기"

→ 결과: Battle of Salamis (480 BCE)
         "테르모필레의 지연이 아테네 해군의 준비 시간을 벌어줌"
```

화살표를 클릭하면 → 지구본이 해당 사건 위치로 날아감.
이것을 반복하면 → 인과관계의 사슬을 따라 역사를 여행할 수 있음.

**지구본 위에서:**
REGIONAL 줌에서 이벤트 마커 사이에 화살표가 보인다.
Marathon → Thermopylae → Salamis → Plataea.
시간순서이자 인과순서가 공간 위에 펼쳐진다.

### 3. 사건의 계층 (event hierarchy)

하나의 큰 사건은 작은 사건들을 포함한다:
```
Greco-Persian Wars (499-449 BCE)
  ├─ Ionian Revolt (499-493 BCE)
  ├─ First Persian Invasion (492-490 BCE)
  │   └─ Battle of Marathon (490 BCE)
  └─ Second Persian Invasion (480-479 BCE)
      ├─ Battle of Thermopylae (480 BCE)
      ├─ Battle of Salamis (480 BCE)
      └─ Battle of Plataea (479 BCE)
```

이것은 인과관계가 아니다. 포함관계다.
`parent_event_id`와 `hierarchy_level`로 표현된다.

**유저 경험:**
CONTINENTAL 줌에서 "Greco-Persian Wars"라는 큰 마커가 보인다.
줌인하면 (REGIONAL) 그 마커가 풀어지면서 개별 전투 마커들이 나타난다.
더 줌인하면 (LOCAL) 각 전투의 하위 이벤트(Day 1, Day 2...)가 나타난다.

**줌이 서사의 해상도인 이유가 바로 이것이다.**

## 스레드: 한 사람의 여정

스레드는 한 인물이 참여한 이벤트들을 시간순으로 엮은 것이다.

```
알렉산더의 여정:
  336 BCE  Pella — 왕위 계승
  334 BCE  Granicus — 첫 승리
  333 BCE  Issus — 다리우스와 첫 대결
  331 BCE  Gaugamela — 결정적 승리
  330 BCE  Persepolis — 페르시아 수도 점령
  326 BCE  Hydaspes — 인도 원정
  323 BCE  Babylon — 사망
```

이것을 지구본 위에 표시하면:
펠라에서 시작하는 선이 소아시아를 관통하고, 이집트를 거치고,
메소포타미아를 지나 페르시아를 관통하고, 인도까지 뻗어나간다.

**유저는 한 사람의 발자취를 지구본 위에서 따라간다.**

## 왜 연결이 본질인가

연결 없이는:
- 이벤트는 고립된 사실이다 (연도 + 장소 + 이름)
- 인물은 데이터베이스 항목이다 (이름 + 생몰년)
- 장소는 좌표다 (위도 + 경도)

연결이 있으면:
- 이벤트는 **이야기의 한 장면**이다 (앞뒤가 있고, 이유가 있다)
- 인물은 **관계의 그물 안에 있는 사람**이다 (스승이 있고, 적이 있다)
- 장소는 **사건이 겹겹이 쌓인 무대**이다 (여기서 이 일이, 저 일이)

CHALDEAS가 주고 싶은 경험은:
**"아, 그래서 그렇게 된 거구나"**라는 깨달음이다.
그 깨달음은 연결에서만 나온다.
