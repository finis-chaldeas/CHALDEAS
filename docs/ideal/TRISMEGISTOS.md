# TRISMEGISTOS — 정보 종합 포털 기획서

## 한 문장

**"뭘 봐야 할지 모르는 사람이 열면 볼 거리가 눈에 들어오고, 관심사가 있는 사람은 원하는 걸 찾아갈 수 있는 곳."**

글로브가 "직접 돌아다녀"라면, 트리스메기스토스는 **"이거 재밌어, 이것부터 봐"**다.
히스토리 시프트 브라우저가 "뭘 볼지 아는 사람의 검색"이라면, 트리스메기스토스는 **큐레이션 + 카테고리 포털**이다.

---

## 모티브: FGO의 터미널

Fate/Grand Order를 처음 켜면 터미널(홈 화면)이 있다.
거기엔 "지금 하면 좋은 것"이 있다: 이벤트 배너, 추천 퀘스트, 새 스토리, 오늘의 보상.
유저는 아무거나 눌러도 된다. **선택지가 큐레이션되어 있으니까.**

트리스메기스토스는 CHALDEAS의 터미널이다.
"뭘 해야 하지?"에 대한 답을 **매번 다르게** 보여준다.

## 현재 상태와 문제점

### 현재 구조

4탭 모달: Era | FGO | Reading | Explore

### 문제 요약

| # | 문제 | 상세 |
|---|------|------|
| 1 | **정체성 혼란** | 4탭이 각각 다른 시스템. "이게 뭐하는 곳이지?" |
| 2 | **3단계 탭** | 모달탭 → FGO/PanHuman → singularity/lostbelt/... = 2-탭 규칙 위반 |
| 3 | **매번 같은 화면** | 열 때마다 같은 정적 목록. 재방문할 이유 없음 |
| 4 | **콘텐츠 빈곤** | 총 16개 JSON 아이템. "아카이브"라기엔 빈약 |
| 5 | **글로브 단절** | 풀스크린 모달이 글로브 100% 가림 |
| 6 | **중복** | Explore=PersonTab, Servants=ServantTab — Navigator에 이미 있음 |
| 7 | **진입 동기 부재** | FGO를 "시작점"으로 쓰겠다는 원래 의도가 구현되지 않음 |

**핵심**: 트리스메기스토스는 "아카이브 카탈로그"가 아니라 **"매거진 홈"**이어야 한다.

## 재설계: 2-Layer 포털

### 컨셉

**Layer 1 — 매거진 홈 (현관문)**
열 때마다 다른 얼굴을 보여주는 큐레이션 홈.
넷플릭스 홈, 스팀 스토어, FGO 터미널처럼 — "지금 추천하는 것"이 매번 바뀐다.

**Layer 2 — 컬렉션 포털 (내부)**
관심사가 생긴 사람이 들어가는 곳. 주제별로 시프트·아티클·이벤트·인물을 모아놓은 "전시실".
철학사가 궁금한 사람, FGO 메인 스토리를 따라가고 싶은 사람, 전쟁사만 보고 싶은 사람 — 각자의 입구가 있다.

```
[매거진 홈]  →  클릭  →  [컬렉션 페이지]  →  클릭  →  [개별 콘텐츠]
  오늘의 역사          "그리스-페르시아 전쟁"      시프트, NarrativePanel,
  추천 카드들           컬렉션 내 시프트/글/인물     또는 글로브 이동
  FGO 진입점
```

## 섹션별 상세

### 1. 오늘의 역사 (히어로 배너)

**최상단에 가장 크게.** 열 때마다 다른 내용.

| 소스 | 로직 | 예시 |
|------|------|------|
| **오늘 날짜 매칭** | DB events에서 오늘 날짜(월/일) 매칭하는 중요 사건 | 3/15 → 카이사르 암살 |
| **이달의 테마** | 수동/자동 큐레이션. 3월=로마, 4월=르네상스 등 | "3월 특집: 로마 공화정의 몰락" |
| **시즌 큐레이션** | 계절/기념일 기반 | 7/4 → 미국 독립, 연말 → "올해의 역사" |
| **랜덤 명장면** | 중요도 상위 이벤트에서 랜덤 | "오늘의 발견: 로제타석" |

**우선순위**: 오늘 날짜 매칭 > 이달 테마 > 랜덤.

**CTA 버튼**:
- `[🌍 글로브에서 보기]` → 모달 닫기, 글로브 이동, NarrativePanel 열기
- `[▶ 시프트로 체험]` → 관련 시프트가 있으면 ShiftPanel 열기

**백엔드 필요**:
```
GET /api/v1/featured/today
→ { event, theme?, shift? }

이벤트: events 테이블에서 month/day 매칭 + importance 정렬
테마: featured_themes 테이블 (월별 수동 큐레이션) 또는 하드코딩
```

### 2. 이번 주 추천 (카드 로우)

**혼합 큐레이션**. 다양한 콘텐츠 타입을 섞어서 4~6개 카드.

카드 타입:

| 타입 | 아이콘 | 소스 | 클릭 시 |
|------|--------|------|---------|
| 시프트 | ▶ | `/shifts?featured=true` | ShiftPanel 열기 |
| FGO 아티클 | ⚔ | `/showcases/fgo/*` | 디테일 뷰 |
| 읽을거리 | 📖 | `/showcases/history,literature,music` | 디테일 뷰 |
| 에세이 | 📝 | `/histories?featured=true` | HistoryViewer |
| 인물 스포트라이트 | 👤 | `/persons?importance>8` | NarrativePanel |
| 테마 컬렉션 | 🏛 | 수동 큐레이션 | 필터된 목록 뷰 |

**카드 디자인**: 작은 직사각형. 제목(2줄) + 타입 라벨 + 부가 정보(시간/페이지 수).

**큐레이션 로직 (초기)**:
1. featured 시프트 2개
2. FGO 서번트 컬럼 1개 (랜덤)
3. 읽을거리 아티클 1개 (랜덤)
4. 나머지: 최근 추가 콘텐츠 또는 인기 콘텐츠

**큐레이션 로직 (미래)**:
- 유저 열람 이력 기반 추천
- "그리스를 많이 봤으니 로마도 보시겠어요?"

### 3. 특이점에서 시작하기 (FGO 섹션)

**FGO를 모르는 사람에게도 작동해야 한다.**

도입 문구:
> "FGO를 아시나요? 게임 속 특이점은 실제 역사를 배경으로 합니다.
> 각 특이점의 진짜 역사를 지구본 위에서 체험해보세요.
> FGO를 모르셔도 괜찮습니다 — 재미있는 역사 이야기입니다."

**구조**: 카테고리 헤더 + 카드 그리드 (탭 없음)

```
특이점
  F. Fuyuki → I. Orleans → ... → VII. Babylonia

이문대
  1. Anastasia → ... → 5. Olympus

서번트 열전
  Gilgamesh · Leonidas · ...
```

**카드에 보여줄 것**:
- 챕터 번호 + 이름
- 연도 + 장소
- **대표 서번트 이름 1~2명** (FGO 유저의 관심 hook)
- 한 줄 요약

**FGO를 "진입점"으로 쓰는 방법**:
- 특이점 카드 클릭 → 디테일 뷰에서 "이건 실제로 ~에서 일어난 일이에요" 설명
- 관련 서번트 클릭 → 실제 역사 인물 NarrativePanel로 연결
- "관련 시프트" 버튼 → 해당 시대/지역 시프트 시작
- **게임에서 시작, 역사로 빠져드는 경로**

### 4. 읽을거리 (하단)

역사·문학·음악 아티클 + 유저 에세이 통합 리스트.

**필터 칩**: 전체 | 역사 | 문학 | 음악 | 에세이

**정렬**: 추천순 (default) | 최신순 | 연도순

**에세이 작성 CTA**: 리스트 상단에 `[+ 새 에세이 작성]`

## 테마 큐레이션 시스템

"매번 같은 화면"을 깨는 핵심.

### 방법 1: 날짜 기반 자동 큐레이션 (v1)

```python
# 오늘 3월 15일 → events 테이블에서 month=3, day=15인 이벤트
# 결과: 카이사르 암살 (44 BCE), 메인 주 (1820), ...
# importance 상위 1개를 히어로 배너로

# 이달 → events 테이블에서 month=3인 중요 이벤트들
# 결과: 카이사르 암살, 미국 독립전쟁 관련, ...
# "이번 주 추천"에 혼합
```

**장점**: 완전 자동. 데이터만 있으면 동작.
**단점**: DB에 월/일 데이터가 있는 이벤트만 가능. 대부분의 고대 이벤트는 정확한 날짜 없음.

### 방법 2: 수동 테마 큐레이션 (v1.5)

```json
// featured_themes 테이블 또는 JSON
{
  "month": 3,
  "theme": "로마 공화정의 몰락",
  "theme_ko": "로마 공화정의 몰락",
  "description": "카이사르부터 아우구스투스까지, 공화정이 제정으로 바뀐 격변의 시대",
  "featured_events": [1001, 1002, 1003],
  "featured_persons": [501, 502],
  "featured_shifts": [10, 11],
  "featured_showcases": ["servant-caesar"]
}
```

**장점**: 편집 의도가 담김. "이번 달엔 이걸 밀자" 가능.
**단점**: 수동 작업 필요.

### 방법 3: AI 큐레이션 (v2)

```
입력: 오늘 날짜, 유저 열람 이력, 현재 글로브 위치/시간
출력: 추천 카드 6개 + 히어로 배너 1개 + 한 줄 테마 문구

"3월 15일, 로마 근처를 보고 계시네요.
 오늘은 율리우스 카이사르가 암살된 날입니다.
 카이사르의 생애를 따라가 볼까요?"
```

## Layer 2: 컬렉션 포털

### 컨셉

매거진 홈이 "오늘 뭐 볼까?"라면, 컬렉션은 **"이 주제를 깊게 파고 싶어"**다.
하나의 주제 아래에 시프트, 아티클, 이벤트, 인물이 한데 모여 있다.
**위키피디아 카테고리 + 넷플릭스 장르 페이지** 같은 느낌.

### 와이어프레임: 컬렉션 목록 (매거진 홈에서 진입)

매거진 홈의 각 추천 카드 / FGO 특이점 카드 / 읽을거리 뒤에 **상위 컬렉션 링크**가 붙는다.
별도 "컬렉션 탐색" 섹션도 매거진 하단에 배치.

### 컬렉션 데이터 모델

```
collections 테이블 (또는 JSON)
├── id: string (slug)
├── type: 'fgo_storyline' | 'era' | 'theme' | 'content'
├── title / title_ko / title_ja
├── description / description_ko / description_ja
├── icon: string (이모지 or 아이콘 ID)
├── cover_image?: string
├── sort_order: number
│
├── shift_ids: number[]           — 연결된 시프트
├── showcase_ids: string[]        — 연결된 아티클
├── event_ids: number[]           — 관련 이벤트 (자동 or 수동)
├── person_ids: number[]          — 관련 인물 (자동 or 수동)
│
├── tags: string[]                — 자동 매칭용 ('greece', 'philosophy', ...)
└── featured: boolean             — 매거진 홈에 노출 여부
```

**자동 매칭**: `tags`가 있는 컬렉션은 시프트/이벤트/인물의 태그와 자동 매칭.
**수동 오버라이드**: `shift_ids` 등으로 수동 지정도 가능 (FGO는 완전 수동).

### 네비게이션 플로우

```
┌─ 매거진 홈 ─┐
│ 오늘의 역사  │──→ 글로브 이동 + NarrativePanel
│ 추천 카드    │──→ 시프트 / 아티클 / 컬렉션
│ FGO 진입점   │──→ FGO 스토리라인 컬렉션
│ 읽을거리     │──→ 아티클 디테일
│ 컬렉션 목록  │──→ 컬렉션 상세 페이지
└──────────────┘
       │
       ▼
┌─ 컬렉션 상세 ─┐
│ 시프트 목록    │──→ ShiftPanel (글로브 위)
│ 아티클 목록    │──→ 아티클 디테일 (사이드 패널)
│ 인물 목록      │──→ NarrativePanel (글로브 위)
│ 이벤트 목록    │──→ 글로브 이동 + NarrativePanel
└────────────────┘
       │
       ▼
┌─ 개별 콘텐츠 ─┐
│ 항상 글로브와   │
│ 연결됨         │
└────────────────┘
```

**뒤로가기**: 컬렉션 상세 → `[← 홈]` → 매거진 홈. 브라우저 뒤로가기 지원.
**깊이**: 최대 3단계 (홈 → 컬렉션 → 콘텐츠)지만, 2-탭 규칙은 유지:
- 콘텐츠까지 2클릭 (추천 카드 클릭 → 바로 시프트/아티클)
- 컬렉션 경유 시 3클릭이지만, 컬렉션 자체가 "탐색 UI"이므로 허용

## 글로브 연결

### 원칙

트리스메기스토스의 모든 콘텐츠는 **글로브로 가는 문**이다.
읽기만 하고 끝나는 게 아니라, "이 장소를 직접 봐"로 연결되어야 한다.

### 방법

| 콘텐츠 | 글로브 연결 |
|--------|-----------|
| 오늘의 역사 | `[🌍 글로브에서 보기]` → 모달 닫기 + flyTo + NarrativePanel |
| 추천 시프트 | 클릭 → ShiftPanel (글로브 위에서 시나리오 재생) |
| FGO 특이점 | 디테일에서 `[지구본에서 보기]` → flyTo(해당 위치, 해당 연도) |
| FGO 서번트 | "원전 인물 보기" → 실제 인물의 NarrativePanel |
| 읽을거리 관련 이벤트 | 이벤트 클릭 → flyTo + NarrativePanel |

### 모달 형태

| 뷰 | 형태 | 글로브 가시성 |
|----|------|-------------|
| 트리스메기스토스 홈 (목록) | 풀스크린 or 하프 모달 | 판단 유보 (구현 시 결정) |
| 디테일 뷰 | NarrativePanel 위치 (오른쪽 사이드) | 글로브 보임 |
| 시프트 진입 | ShiftPanel (기존) | 글로브 위에서 작동 |

## 데이터 요구사항

### 새로 필요한 API

```
GET /api/v1/featured/today
  → 오늘의 역사 이벤트 (month/day 매칭 + importance 정렬)
  → 이달의 테마 (optional)

GET /api/v1/featured/recommendations
  → 혼합 추천 카드 리스트
  → [{ type: 'shift'|'showcase'|'history'|'person'|'collection', id, title, ... }]

GET /api/v1/collections
  → 전체 컬렉션 목록 (매거진 홈의 "컬렉션 둘러보기")
  → [{ id, type, title, icon, counts: { shifts, articles, persons, events } }]

GET /api/v1/collections/:slug
  → 컬렉션 상세 (시프트, 아티클, 인물, 이벤트 포함)
  → { ...collection, shifts: [...], showcases: [...], persons: [...], events: [...] }
```

