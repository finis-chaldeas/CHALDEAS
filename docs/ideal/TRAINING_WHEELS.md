# 초보자의 보조바퀴

## 문제

지구본을 줬다. "탐험해."
역사를 모르는 사람은 어디서 시작해야 할지 모른다.
뭘 눌러야 하는지 모른다. 뭘 보고 있는지 모른다.

**자유도가 높으면 아무것도 못 한다.**

그래서 보조바퀴가 필요하다.
처음에는 레일 위에서 달리게 해주고,
익숙해지면 레일을 벗어나 자유 탐험으로 나가게 한다.

---

> **통합 안내**: 가이드 투어 (시대별/장소별/인물별 투어)는 **히스토리 시프트**로 통합되었습니다.
> 시프트의 5가지 유형이 아래의 모든 투어 유형을 포함합니다.
> 상세 기획은 → [HISTORY_SHIFT.md](./HISTORY_SHIFT.md) 참조.

## 보조바퀴 1: 가이드 투어

### 시대별 투어

미리 짜여진 코스. 넷플릭스 다큐처럼 에피소드 구성.

```
[그리스-페르시아 전쟁] 7단계
  1. 이오니아 반란 (499 BCE, 밀레투스)
  2. 마라톤 전투 (490 BCE, 마라톤)
  3. 크세르크세스의 출정 (480 BCE, 수사)
  4. 테르모필레 전투 (480 BCE, 테르모필레)
  5. 살라미스 해전 (480 BCE, 살라미스)
  6. 플라타이아 전투 (479 BCE, 플라타이아)
  7. 그리스의 승리와 그 후 (478 BCE, 아테네)
```

각 단계에서:
- 지구본이 자동으로 해당 위치로 날아감
- 간결한 이야기가 나옴 (3~5문장)
- "다음" 버튼을 누르면 다음 단계로
- 중간에 나가서 자유 탐험해도 됨

**시대별 투어 예시:**
- 고대: 메소포타미아의 탄생, 이집트 왕조, 그리스-페르시아
- 고전: 알렉산더의 정복, 로마의 흥망, 한나라
- 중세: 십자군 전쟁, 몽골 제국, 르네상스의 여명
- 근세: 대항해시대, 산업혁명, 미국 독립
- 현대: 세계대전, 냉전, 우주 시대

### 장소별 투어

한 도시/지역의 시간을 따라가는 코스.

```
[이스탄불의 3000년] 10단계
  1. Byzantium의 건설 (667 BCE)
  2. 페르시아의 지배
  3. 콘스탄티누스의 천도 (330 CE) — 이름이 Constantinople으로 바뀜
  4. 유스티니아누스의 하기아 소피아 (537 CE)
  5. 제4차 십자군의 약탈 (1204)
  6. 비잔틴 복원 (1261)
  7. 오스만의 정복 (1453) — 이름이 Istanbul로 바뀜
  8. 술레이만 대제 시대
  9. 오스만 제국의 쇠퇴
  10. 터키 공화국 (1923)
```

**장소별 투어의 핵심:**
- 지구본은 움직이지 않는다 (같은 좌표)
- 대신 **시간이** 움직인다
- 영토 오버레이 색이 바뀌고
- 장소 이름이 바뀌고
- 주인공이 바뀐다
- "같은 장소인데 완전히 다른 세계가 된다"

### 인물별 투어

한 인물의 생애를 따라가는 코스.

```
[알렉산더의 여정] 12단계
  1. Pella (356 BCE) — 출생
  2. Mieza (343 BCE) — 아리스토텔레스에게 배움
  3. Chaeronea (338 BCE) — 첫 전투
  4. Pella (336 BCE) — 왕위 계승
  5. Granicus (334 BCE) — 페르시아 원정 시작
  6. Issus (333 BCE) — 다리우스와 첫 대결
  7. Tyre (332 BCE) — 7개월 포위전
  8. Alexandria (331 BCE) — 도시 건설
  9. Gaugamela (331 BCE) — 결정적 승리
  10. Persepolis (330 BCE) — 페르시아 수도 점령
  11. Hydaspes (326 BCE) — 인도 원정, 마지막 대전투
  12. Babylon (323 BCE) — 사망
```

**인물별 투어의 핵심:**
- 지구본이 **그 사람의 발자취**를 따라 날아다님
- 각 정거장에서 그 사람이 뭘 했는지, 누구를 만났는지
- 생애 전체가 지구본 위의 선으로 그려짐
- "이 사람이 이만큼 돌아다녔구나"

## 보조바퀴 2: FGO 서번트

### Fate/Grand Order가 왜 보조바퀴인가

FGO를 플레이하는 사람은 이미 역사 인물의 이름을 안다.
길가메시, 알렉산더, 레오니다스, 메디아, 쿠 훌린, 미야모토 무사시.

하지만 게임 속 캐릭터와 실제 역사/신화의 인물 사이에 간극이 있다.
CHALDEAS는 그 간극을 잇는 다리가 된다.

### 유저 경험

```
[FGO 서번트 탐색]

클래스 선택:
  Saber · Archer · Lancer · Rider · Caster · Assassin · Berserker

또는 이름 검색:
  [검색: Gilgamesh]
```

서번트를 선택하면:

```
┌─────────────────────────────┐
│ ⚔ Gilgamesh (Archer)       │
│                             │
│ FGO: 우르크의 영웅왕        │
│ 역사: 우르크의 왕           │
│       (c. 2700 BCE)         │
│       메소포타미아 신화      │
│                             │
│ certainty: mythological     │
│                             │
│ [🌍 지구본에서 보기]         │
│ [📖 서사시 읽기]            │
│ [🔗 관련 서번트]            │
└─────────────────────────────┘
```

"지구본에서 보기"를 누르면:
→ 지구본이 메소포타미아 우루크로 날아감
→ 기원전 2700년대로 타임라인 이동
→ 우루크 주변 마커들이 보임
→ "아, 우루크가 여기구나. 이 시대에 이집트에서는 피라미드를 짓고 있었네?"

**FGO에서 시작해서 실제 역사/신화로 빠져드는 경로.**

### 관련 서번트 네트워크

FGO 서번트들의 역사적 관계:

```
Gilgamesh
  ├─ Enkidu (친구) — 같은 서사시
  ├─ Ishtar (적대) — 메소포타미아 신화
  └─ Ozymandias (동시대 왕) — 이집트

Alexander
  ├─ Iskandar (본인, Rider 클래스)
  ├─ Aristotle (스승) — 아직 미등장이지만 역사적 관계
  ├─ Darius III (적) — FGO Berserker
  └─ Hephaestion (부관)

Leonidas
  ├─ Xerxes I (적) — 역사적 관계
  └─ Themistocles (동맹) — 그리스 연합
```

서번트의 관계를 따라가다 보면,
FGO 캐릭터들의 **실제 역사적 맥락**을 자연스럽게 알게 된다.

### 서번트 투어

FGO 세계관에 맞춘 가이드 투어:

```
[제7특이점: 바빌로니아] — 우루크 투어
  1. 우루크 (2700 BCE) — 길가메시의 도시
  2. 시나르 평원 — 엔키두와의 만남
  3. 삼나무 숲 — 훔바바 토벌
  4. 우루크 — 이슈타르의 분노
  5. 저승 — 엔키두의 죽음
  6. 세계의 끝 — 불사의 탐색

[제5특이점: 카멜롯] — 아서왕 전설 투어
[제1특이점: 오를레앙] — 잔 다르크 투어
```

FGO의 특이점(Singularity) 구성을 그대로 따라가되,
게임 스토리가 아니라 **실제 역사/신화**로 안내한다.

매일 접속할 때마다 다른 시작점을 제안:

```

```

## 보조바퀴에서 자유 탐험으로

보조바퀴의 목적은 **영원히 달아놓는 것이 아니다.**

투어를 따라가다가 중간에 "저건 뭐지?" 하고 옆길로 새는 순간,
보조바퀴가 빠지고 자유 탐험이 시작된다.

```
투어 3단계에서 "크세르크세스"가 언급됨
  → 누름
  → 크세르크세스 인물 카드
  → "아, 이 사람 페르시아 왕이었구나"
  → 페르시아 쪽 마커가 보임
  → "페르세폴리스? 이건 뭐지?"
  → 누름
  → 투어에서 이탈, 자유 탐험 중
```

좋은 보조바퀴는:
1. **시작점을 준다** (어디서부터 볼지)
2. **맥락을 준다** (이게 왜 중요한지)
3. **호기심을 만든다** (다음에 뭐가 있을까)
4. **벗어나기 쉽다** (아무 때나 자유 탐험으로)

## 정리

| 보조바퀴 | 대상 | 시작점 |
|---------|------|--------|
| 시대별 투어 | 역사에 관심은 있지만 어디서 볼지 모르는 사람 | "그리스-페르시아 전쟁" 같은 유명 시대 |
| 장소별 투어 | 여행을 좋아하거나 특정 도시에 관심 있는 사람 | "이스탄불의 3000년" 같은 장소 |
| 인물별 투어 | 특정 인물에 관심 있는 사람 | "알렉산더의 여정" 같은 위인 |
| FGO 서번트 | FGO 플레이어 | 좋아하는 서번트 |
| 오늘의 역사 | 매일 가볍게 들르는 사람 | 오늘 날짜의 사건 |
| 도메인별 | 특정 분야에 관심 (과학, 철학, 군사) | "과학의 역사" 같은 주제 |

모든 보조바퀴의 결론은 같다:
**지구본 위에서 시작하고, 지구본 위에서 탐험하게 한다.**
