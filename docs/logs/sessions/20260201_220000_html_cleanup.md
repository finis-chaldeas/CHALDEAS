## 2. clean_html() 개선

**파일**: `poc/scripts/unified/extract_wikipedia.py`

**추가된 패턴**:
```python
# CSS 주석 제거 (/* ... */)
text = re.sub(r'/\*[^*]*\*+(?:[^/*][^*]*\*+)*/', ' ', text)
# 불완전한 CSS 주석 제거 (시작/끝만 있는 경우)
text = re.sub(r'/\*.*$', '', text)  # /* 이후 끝까지
text = re.sub(r'^[^/]*\*/', '', text)  # 시작부터 */ 까지
# CSS 클래스 잔재 제거 (.mw-*, .geo-*, .reference 등)
text = re.sub(r'\.[a-z][a-z0-9-]*', ' ', text)
```
