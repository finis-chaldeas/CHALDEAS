**문제**: Welcome Experience를 만들었지만, 실제로 앱에 들어온 후에도 여전히 뭘 해야 할지 모르겠다.
**핵심**: 3가지 경로 제시만으로는 부족. 들어온 후의 가이드가 없다.

## 피드백 2: 시대/장소 타겟팅 후 액션 부재
> "이 시대, 이 장소 타겟팅했을 때 뭘 해야할지도 모르겠는 거지같은 디자인"

**문제**: 글로브에서 특정 시대/장소로 이동했는데, 그 다음 뭘 해야 하는지 안내가 없다.
**핵심**: Context Banner가 있어도 actionable한 다음 스텝이 부족.

## 피드백 3: 50년 단위 Period Detail이 평면적
> "50년 단위는 기준이지, 그 시대 안의 지역별 주요 사건들을 더 세분해서 해야지. 보기 쉽게 하는 게 더 중요하다. 관심있게 구성해야지."

**좋은 점**: 50년 단위 분할 자체는 OK
**문제**: Period Detail에 들어가면 사건이 그냥 나열됨. 지역별/테마별 세분화 없음.
**해결 방향**: Period 내에서 지역별 그룹핑, 주요 사건 하이라이트, 스토리 구성 필요.

## 피드백 4: 장르/카테고리 시스템 무의미
> "장르별로 나눴는데 그거 아무런 의미가 없는 상황. 히스토리 체인도 아무런 의미가 없고"

**문제**: category (battle, politics, science 등) 분류가 사용자 경험에 반영되지 않음.
**문제**: Historical Chain 기능이 사용자에게 가치를 제공하지 못함.
**핵심**: 분류 체계가 있어도 그걸 활용한 탐색/필터/추천이 없으면 의미 없음.

## 피드백 5: 큐레이션 콘텐츠 분리 필요
> "큐레이션된 건 따로 볼 수 있도록 작업해야지. AI/휴먼 큐레이션된 거만 볼 수 있도록 구성해야 하고. 트리스메기스토스가 그 역할을 해줄 수 있을 것 같은데"

**문제**: AI 내러티브, 인간 큐레이션 콘텐츠가 raw 데이터와 섞여 있음.
**해결 방향**: Trismegistus를 큐레이션 콘텐츠 전용 뷰어로 확장.
- AI 생성 내러티브만 모아보기
- 인간 큐레이션 체인만 모아보기
- 품질 보증된 콘텐츠 vs raw 데이터 구분

## 피드백 6: 쓰레기 데이터 + 정정 메커니즘 부재
> "Jack the Ripper가 879년? 쓰레기 데이터가 한가득인데, 그거 정정할 문의나 그런 거 할 구성은 해뒀냐?"

**구체적 예시**: 잭 더 리퍼 → 879 CE, Unknown location, "기록 검증 대기 중"
**문제 1**: 명백히 잘못된 데이터가 사용자에게 그대로 노출됨
**문제 2**: 사용자가 잘못된 데이터를 신고/정정할 수 있는 UI가 없음
**해결 방향**:
- 데이터 신뢰도 표시 (검증됨/미검증/오류 의심)
- "Report Error" 버튼 추가
- 미검증 데이터 필터링 옵션

## 피드백 7: 데이터 모델 오류 - 인물이 이벤트로 등록됨
> "Leonardo da Vinci가 이벤트? 왜 사람이 이벤트냐"

**구체적 예시**: Event #11363669 = "Leonardo da Vinci", 1452 CE, Unknown, Various, general
**문제**: Person 엔티티가 Event 테이블에 들어가 있음. 데이터 임포트/파이프라인 문제.
**영향**: 사용자 신뢰 완전 파괴. 기본적인 데이터 정합성이 안 됨.
**해결 방향**:
- Event 테이블에서 Person으로 잘못 들어간 데이터 식별/정리
- 파이프라인에서 entity type 분류 로직 점검
- "기록 검증 대기 중" 상태의 이벤트는 사용자에게 노출하지 않거나 별도 표시
