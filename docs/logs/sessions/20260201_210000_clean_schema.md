## 1. connections 테이블 생성 (완료)

**파일**: `backend/alembic/versions/200_create_connections_table.py`

**스키마** (CLEAN_SCHEMA_PLAN.md 기반):
```sql
CREATE TABLE connections (
    id SERIAL PRIMARY KEY,

    -- From entity
    from_type VARCHAR(20) NOT NULL,  -- person, location, event
    from_id INTEGER NOT NULL,
    from_qid VARCHAR(20),            -- Wikidata QID

    -- To entity
    to_type VARCHAR(20) NOT NULL,
    to_id INTEGER NOT NULL,
    to_qid VARCHAR(20),

    -- Relation
    relation VARCHAR(50) NOT NULL,

    -- Evidence (필수!)
    evidence TEXT NOT NULL,

    -- Source tracking
    source_url VARCHAR(500),
    source_type VARCHAR(20),        -- wikipedia, wikidata, book
    confidence FLOAT DEFAULT 0.7,

    created_at TIMESTAMP DEFAULT NOW()
);
```

**핵심**: `evidence TEXT NOT NULL` - 모든 연결에 근거 필수
