# Refactor Skill

대규모 리팩토링 작업을 체계적으로 수행합니다.

## 사용법

```
/refactor <대상> <목표>
예: /refactor auth module 타입 안전성 강화
```

## 실행 순서

1. **영향 분석**
   - 대상 파일/모듈 식별
   - 의존성 파일 목록 생성
   - 변경 영향도 평가

2. **작업 계획**
   - 파일을 논리적 그룹으로 분류
   - 수정 순서 결정 (의존성 고려)
   - 각 그룹별 예상 변경 사항

3. **순차 수정**
   - 그룹 1 수정 → 검증 → 커밋
   - 그룹 2 수정 → 검증 → 커밋
   - ...반복

4. **통합 검증**
   - 전체 테스트 실행
   - 타입 체크
   - 린트 검사

## 출력 형식

```
## 리팩토링 계획

### 영향 받는 파일 (N개)
- 그룹 1: [파일 목록]
- 그룹 2: [파일 목록]

### 수정 진행
- [x] 그룹 1 완료
- [ ] 그룹 2 진행 중
- [ ] 그룹 3 대기

### 검증 상태
✅ 테스트 통과
✅ 타입 체크 통과
```
